### Featured Projects

**[Dubbio](https://github.com/Amir-Shaban32/dubbio)** — *Graduation Project*
AI dubbing platform that lets a studio clone its voice actors' voices once, then dub foreign videos with those voices and review every line before export.
`NestJS` `TypeScript` `PostgreSQL` `Drizzle ORM` `Docker` `Cloudflare R2` `ElevenLabs` `TwelveLabs`
- Designed a provider-agnostic AI adapter layer, so voice and video providers (ElevenLabs, TwelveLabs) can be swapped without changing business logic
- Built the media pipeline: users upload source videos and voice samples, stored in Cloudflare R2 object storage
- Implemented a line-by-line review and editing workflow so users can correct translations and regenerate individual segments
- Modeled projects, voices, and dubbing jobs in PostgreSQL with Drizzle ORM, with job status tracking for long-running AI tasks

**[Sporva](https://github.com/Amir-Shaban32/Sporva)** — *In Progress*
League management REST API covering teams, fixtures, match results, standings, news, and player ratings.
`TypeScript` `Express` `PostgreSQL` `Prisma` `Docker` `Redis`
- Relational schema for leagues, seasons, teams, players, and matches, with migrations managed by Prisma
- Standings calculated from recorded match results
- JWT authentication with role-based access for admins and editors
- Containerized with Docker Compose (API + database) for one-command local setup
